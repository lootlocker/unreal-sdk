TArray<FLootLockerIdentityProviderInfo> FLootLockerIdentityResponse::providers

The provider credentials linked to this identity.

Only GetIdentity loads these. Lookup and merge share this shape but have no reason to carry them, so expect HasProviders to be false there, which is distinguishable from an identity with no credentials linked (HasProviders true, empty array).
