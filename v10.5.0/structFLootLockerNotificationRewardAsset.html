Detailed Description

Represents an asset reward in a notification, linking the reward to an asset and its optional variation or rental option.

◆ Asset_instance_ids

TArray<int64> FLootLockerNotificationRewardAsset::Asset_instance_ids

The IDs of the Asset Instances that were granted.

Will be empty if the reward did not result in any asset instance grants. For multi-quantity purchases all granted instance IDs are listed. For group rewards each nested asset entry carries its own Asset_instance_ids.
