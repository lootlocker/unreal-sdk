const FString & ForPlayerWithUlid = "" )
static

Record that the calling player acknowledged a playtest document at its current content hash.

When the document has statements, send every statement id. Leave the request's statement_ids empty for documents without statements, where the body is optional.

Parameters
SubdomainThe playtest's public subdomain
DocumentIdThe ULID of the document to acknowledge
RequestThe acknowledge request. See FLootLockerAcknowledgePlaytestDocumentRequest.
OnCompleteDelegate for handling the server response
ForPlayerWithUlidOptional: Execute for the specified player ULID (default player if empty)
Returns
A unique id for this request, use this to match callbacks to requests when you have multiple simultaneous requests outbound

Complete onboarding for the calling player.

Answers are submitted separately through the player metadata API using each question's metadata_key. The request fails when a required answer is missing or a required document is not acknowledged at its current content hash.

Submit answers to a playtest for the current player.

Playtest answers are stored as player metadata, so this writes each answer to the player's own metadata under the question's metadata_key. Call CompletePlaytestOnboarding afterwards to record the completion.
