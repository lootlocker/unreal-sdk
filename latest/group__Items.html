Items
Player

Detailed Description

These methods operate on items and item templates.

They are unrelated to the asset-based inventory API above (GetInventory, ListPlayerInventory, ...), which deals with assets and asset instances. The two share a URL prefix but are separate systems.

Instanced

Stackable 

The item is stored as a single entry with a count that can be incremented or decremented.
