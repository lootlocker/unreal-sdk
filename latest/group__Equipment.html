Equipment

Detailed Description

Attach inventory stacks to game-defined equipment slots and read loadouts.

A publisher defines equipment groups per game, each bound to one entity type (player today), and slots inside them. A slot carries tags and a max_items cap; it accepts a stack only when the item template shares at least one of the slot's tags. Equipping a stack larger than the cap splits it, and equipped stacks leave the normal inventory listing until unequipped. Every loadout read is paged over groups, and each attached stack reports valid and over_limit so config drift is visible instead of silent.

See the LootLocker documentation.

◆ ELootLockerEquipmentReplaceMode

enum class ELootLockerEquipmentReplaceMode : uint8
strong

Whether an occupied equipment slot should be auto-unequipped when equipping into it.

Enumerator
Unset 

Leave replace out of the request so the server applies its own default.

Replace 

Auto-unequip the stack already occupying the slot.

Conflict 

Do not replace the occupant; the request fails with a conflict instead.

Equip an inventory stack into an equipment slot.
